# Azure DevOps Terraform Demo

Proyecto demo técnico orientado a una posición de **DevOps & Cloud Engineer**, enfocado en demostrar buenas prácticas de:

- CI/CD con Azure DevOps Pipelines en YAML
- Infraestructura como código con Terraform
- Despliegue en Azure Static Website
- Flujo de promoción entre ambientes DEV → PROD
- Aprobación manual previa a producción
- Smoke testing post deploy

El frontend está diseñado intencionalmente como una landing page estática y simple, para mantener el foco en la automatización, la infraestructura y el ciclo completo de entrega continua.

## Stack del proyecto
- HTML / CSS estático
- Azure DevOps
- Terraform
- Azure Storage Static Website
- GitHub

## Objetivo
Construir un demo chico, profesional y defendible en entrevista técnica, priorizando:

- automatización
- reproducibilidad
- separación por ambientes
- buenas prácticas DevOps
- despliegues seguros
